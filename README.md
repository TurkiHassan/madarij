# مدارج — نموذج تجريبي

منصة عربية لخطط صعوبات التعلم الفردية: هدف قابل للقياس، خطة قصيرة، نشاط، مسبار قراءة أسبوعي، وتقرير جاهز لولي الأمر.

هذه **نسخة تجريبية قابلة للنقر**، مبنية لعرضها على معلمي صعوبات التعلم وجمع ملاحظاتهم، وليست منتجًا إنتاجيًا. البيانات وهمية، ولا يوجد خادم أو قاعدة بيانات.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`.

للنسخة المبنية:

```bash
npm run build
npm run preview
```

> لا تفتح `dist/index.html` بالنقر المزدوج؛ المتصفح يمنع تحميل ملفات الوحدات من `file://`. استخدم `npm run preview` أو أي خادم ملفات ثابت.

## عرضه على المعلمين

1. افتح «دليل العرض» من داخل النموذج، واضغط «جلسة نظيفة» قبل البدء.
2. اجلس بجانب المعلم ودعه يمسك الجهاز. لا تشرح المزايا.
3. اتبع الخطوات الخمس في الدليل (لوحة اليوم ← ملف فيصل ← مسبار ← نشاط ← تقرير).
4. بعد كل شاشة، اسأله الأسئلة الخمسة الموجودة في الدليل.
5. سجّل ملاحظة من زر «ملاحظة» أسفل كل شاشة (تقييم سريع + جملة).
6. بعد الجلسة، افتح «ملاحظات المعلمين» وصدّر CSV أو JSON.

## مكتبة المعايير الرسمية

المعايير منقولة **حرفيًا** من «الاختبارات التشخيصية لذوي صعوبات التعلم في مادتي اللغة العربية والرياضيات بالمرحلة الابتدائية» — الإدارة العامة للتربية الخاصة والإدارة العامة للتقويم وجودة التعليم، وزارة التعليم، ١٤٣٧/١٤٣٨هـ (٤٤ معيارًا للغة العربية: ١٣+٦+٥+٧+٦+٧). الترميز: الرقم الأول من اليمين للصف والثاني للمعيار (م ٥/١ = المعيار الخامس للصف الأول).

- **لكل معيار عدّة تدريس:** عرض تقديمي بمراحل الدرس (تهيئة/عرض/أنشطة متخللة/خاتمة)، أنشطة تفاعلية بتغذية راجعة بلا مؤقت ولا ترتيب علني، وتقويم ختامي بالمحك الرسمي نفسه.
- **المحك من كراسة المعلم:** م ١/١ = ١٠٠٪ (الحروف كلها)، م ٥/١ = ٦٠٪، م ١٣/١ = ٦٠٪ (٨ كلمات صحيحة من ١٢)، م ١/٢ = ٦٠٪ (٢٤ من ٤٠)، م ٢/٣ نص ١١٠ كلمات. الأعداد تحققت من صور صفحات الملف نفسه. معايير الصفوف ٢–٦ التي لم تُفحص صفحتها بعد تأخذ المحك الافتراضي في ورقة النتائج (٨٠٪)، ويُدقَّق عند بناء عدّتها.
- **جاهزة اليوم:** عدّة كاملة (عرض + أنشطة + تقويم) لكل المعايير الـ٤٤: ١٨ لمعايير القراءة والفهم، و٢٦ لمعايير الكتابة والإملاء. معايير النصوص الشفهية والإملاء من الذاكرة (م ١٣/١، م ١/٢، م ٢/٣، م ١/٤، م ١/٥، م ٣/٦، وكتابات «الذاكرة القريبة/البعيدة») تقويمها «بطاقة معلم»: أملي/اعرض وارصد كلمة الخطأ كما في كراسة الوزارة.
- **الربط بالخطة:** في صفحة الخطة يختار المعلم «ربط بمعيار رسمي» فتُصاغ الصياغة من النص الرسمي، ويظهر رمز المعيار في بطاقة الهدف والتقرير، ونتائج الأنشطة والتقويم الختامي تتغذى على الهدف المرتبط.
- **صياغة الأهداف** في صفحة التعريف وباني الهدف تتبع دليل معلم صعوبات التعلم في المرحلة الابتدائية ١٤٤٢هـ (السلوك/الشرط/المعيار/التاريخ).

روابط المصادر (موقع وزارة التعليم):
- الاختبارات التشخيصية: <https://moe.gov.sa/media/uploads/28/280b03d4d6e6a6d2d776a6a934d8c764a0837ad6f6dc7765cdaff6b7354007e8.pdf>
- دليل معلم صعوبات التعلم في المرحلة الابتدائية ١٤٤٢هـ: <https://moe.gov.sa/media/uploads/94/94e3eedb7f6d45323ebe0b0eecc08d0a34284e6bb5de57e9f8e4e12c82b96fca.pdf>

## ما هو حقيقي وما هو وهمي

**حقيقي في النموذج**

- دورة العمل كاملة: هدف ← خطة ← نشاط ← مسبار ← تقرير.
- مكتبة المعايير الرسمية (٤٤ معيارًا للغة العربية) وكلٌّ منها له عدّة تدريس كاملة: عرض تقديمي، أنشطة تفاعلية، وتقويم ختامي بالمحك الرسمي (أسئلة، أو بطاقة معلم لرصد أخطاء النص الشفهي والإملاء).
- تحرير الخطة وحفظها في المتصفح.
- مسبار بمؤقت 60 ثانية، وتسجيل صحيح/خطأ، وحساب المعدل والدقة، وتحديث الخط.
- أربعة أنشطة عربية (التاء المربوطة/الهاء، الحروف المتشابهة، الفكرة الرئيسة، الحركات).
- تسجيل نتائج الأنشطة في ملف الطالب وأثرها على نسبة إتقان الهدف.
- تقرير للطباعة/PDF بصفحة A4 واحدة.
- ملاحظات المعلمين مع الشاشة والتقييم والتصدير.
- تكبير الخط من أعلى التطبيق (100% / 112% / 125%).

**وهمي أو مؤقت**

- أسماء الطلاب وبياناتهم وقياساتهم: بيانات تجريبية ثابتة.
- لا تسجيل دخول، ولا صلاحيات، ولا قاعدة بيانات، ولا مزامنة بين الأجهزة.
- كل شيء يُحفظ في `localStorage` على هذا المتصفح فقط. «أعد ضبط النموذج» يمسحها.
- لا تُدخل بيانات طالب حقيقي في هذه النسخة.
- الأنشطة أربعة فقط، وليست محرك أنشطة كاملًا.
- عدّات الكتابة تستخدم بطاقة معلم للإملاء (الذاكرة القريبة/البعيدة) وأسئلة للقواعد الإملائية (همزات، ألف لينة، ترتيب، ترقيم).
- لا صوت مسجل، ولا تكامل مع نور أو أي نظام مدرسي.
- التقرير نموذج تصميمي، وليس مستندًا رسميًا معتمدًا.

## الهوية البصرية

- الاتجاه المختار: **ورشة الحكاية (٣)** كهوية، و**غرفة القياس (٢)** كلغة لشاشات البيانات.
- **المكونات من مكتبة أطلس** (`@atlas/ui` ١.١.١ — [TurkiHassan/atlas-components](https://github.com/TurkiHassan/atlas-components)): قوائم الطلاب والنصوص (`Select`)، فلاتر الصف والمجال (`SegmentedControl`)، أشرطة إتقان الأهداف (`Progress`)، لوحة الملاحظات (`Dialog` + `Textarea` + `TextInput`)، وتنبيهات الحفظ (`Notifications`) — كلها بلوحة مدارج وبزوايا حادة عبر `src/styles/atlas.css`.
- **الخطوط من الأعلى إلى الأسفل كما طُلب:** ثمانية (Thmanyah Serif Display للعناوين، Thmanyah Sans للنص) ← KOMission (الأرقام والرموز) ← El Messiri (احتياطي/عناوين ثانوية). ملفات الخطوط مستضافة محليًا في `src/assets/fonts/` وتُعرَّف في `src/styles/fonts.css`.
- الصفحة التعريفية: كوبالت، ورق مقصوص، شريط لاصق، خط Rakkas للعناوين وAlmarai للنص. الهيرو ملف طالب تجريبي (عبدالله) على ورق، وليس صورة زخرفية.
- لوحة اليوم والمسبار والتقدم والتقرير: ورق بياني، أشرطة سوداء، أزرق إشارة `#1F4BFF`، وأرقام بخط Readex Pro. الملف والخطة والأنشطة تبقى ورقية دافئة.
- صورة الميناء التي وُلّدت سابقًا ما زالت مستخدمة كبطاقة بريدية ملصقة في قسم «لماذا مدارج»، وليست خلفية الهيرو.
- مشهد الشرائح المرسوم برمجيًا محفوظ في `src/art/HarborScene.tsx` كبديل، لكن الهيرو الآن لوحة خطة.
- ترتيب الخطوط (أعلى ← أسفل): **ثمانية ← KOMission ← El Messiri**. العناوين بثمانية سيريف ديسبلاي، والنص بثمانية سنس، والأرقام والرموز الثقيلة بـKOMission Black، وEl Messiri للاحتياط والعناوين الثانوية، وAmiri لنصوص القراءة المشكولة فقط. كلها محلية وتعمل بلا إنترنت.
- لا صور فوتوغرافية أو فيديو: الهوية مبنية على الرسم والورق. لوحة الميناء رسم توضيحي وليست صورة فوتوغرافية.

## الخطوات التالية قبل أي استخدام حقيقي

- مقابلات مع 5–8 معلمي صعوبات تعلم، ومراجعة نماذج الخطط الفردية المستخدمة في مدارسهم.
- تعريف نجاح قابل للقياس: وقت إعداد الخطة، دقة الأهداف، انتظام المسبار، رضا المعلم.
- خادم وقاعدة بيانات وصلاحيات (Supabase أو ما يعادلها)، وسياسة احتفاظ وحذف، وموافقة ولي الأمر.
- مراجعة خصوصية بيانات الأطفال وفق نظام حماية البيانات الشخصية السعودي.
- التحقق من معايرة نصوص المسبار ومعدلات القراءة مع مختص، وعدم اعتبار الأرقام الحالية معايير.
- اختبار سهولة الاستخدام مع طلاب من الفئة المستهدفة، لا مع المعلمين فقط.

## اتجاهات بصرية للاختيار

ملف واحد مكتفٍ ذاتيًا: `madarij-directions.html`. افتحه بالنقر المزدوج؛ لا يحتاج خادمًا ولا إنترنتًا.

فيه خمسة اتجاهات كاملة، ولكل اتجاه الصفحة التعريفية وشاشة من التطبيق:

1. **دفتر المعلم** — ورق وخيط وحبر.
2. **غرفة القياس** — أرقام وأدوات قياس.
3. **ورشة الحكاية** — قصاصات وحكايات.
4. **مرصد الأسبوع** — ليل ونجوم وهدوء.
5. **شبكة المسار** — لافتات ومسارات.

اختر الاتجاه من الشريط العلوي أو من نهاية كل اتجاه؛ يُحفظ الاختيار في المتصفح. للاختيار السريع استخدم الأرقام من ١ إلى ٥، وللتنقل بين الاتجاهات الأسهم.

مصادر التعديل في `direction-studio/`. بعد أي تعديل أعد بناء الملف المفرد:

```bash
node direction-studio/build.cjs
```
